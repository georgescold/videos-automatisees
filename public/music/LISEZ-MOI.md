# Musiques d'ambiance

Dépose ici tes musiques libres de droits (`.mp3`, `.wav`, `.m4a`, `.aac`).

- La **première par ordre alphabétique** est utilisée par défaut.
- Pour en choisir une autre : `npm run make -- scripts/mon-script.json --music=nom-du-fichier.mp3`
- Volume par défaut : 10 % sous la voix, avec fondu d'entrée et de sortie automatiques. Ajuste avec `--music-volume=0.08`.

Sources gratuites utilisables sur YouTube sans revendication : la bibliothèque audio YouTube Studio, Pixabay Music, Uppbeat (avec crédit). Vérifie toujours la licence avant publication — un titre sous licence commerciale déclenchera une revendication Content ID sur ta chaîne.

Sans fichier ici, la vidéo sort avec la voix off seule.
